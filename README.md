# 🎵 YouTube Audio Downloader (Windows)

YouTube の動画・プレイリストを  
**高音質な音声ファイル（mp3 / m4a / ogg / wav）としてダウンロード**できる  
Windows 用デスクトップアプリです。

---

## ✨ 主な機能

- 🔗 **YouTube URL を貼り付けるだけ**
- 📁 **プレイリスト対応**
  - 全動画を自動で順番にダウンロード
  - `(1/7) ダウンロード中… → (1/7) 変換中…` のように進捗表示
- 🎧 **対応フォーマット**
  - m4a（おすすめ）
  - mp3
  - ogg
  - wav
- 📊 **リアルタイム進捗表示**
  - ダウンロード進捗（％）
  - ダウンロード速度（MB/s）
  - 変換中はアニメーションバー表示
- 📂 **download フォルダに自動保存**
  - 初回起動時に自動生成
- 🔕 **完了時は音のみ通知**
  - ポップアップなしで静かに完了

---

## 🖥 動作環境

- OS：**Windows 10 / 11**
- ネットワーク：インターネット接続必須
- 追加ソフト：不要（exe 単体で動作）

---

## 🚀 使い方

1. `YouTubeAudioDownloader.exe` を起動
2. **YouTube URL をペースト**
3. ダウンロードしたい **音声形式を選択**
4. **「◯◯でダウンロード」ボタンをクリック**
5. 完了音が鳴ったら終了 🎉

---

## 📁 出力先

download/
├─ 動画タイトル.m4a
├─ 動画タイトル.mp3
├─ 01_動画タイトル.ogg
└─ ...

  **変換完了後に自動削除**されます
